# AnalyticsAng

В наступних версіях:
- Додавання свайпів для більш зручної навігації
- Додавання детального перегляду транзакцій на екрані балансу по кліку на категорію витрат/доходів
- Більше аналітики (Створення окремої сторінки)
- Отримання актуального курсу НБУ по API та розрахунок накопичень
- Архівування даних, для оптимізації памʼяті в БД

### Примітки
Команда для оновлення для github pages: 
- ng deploy --base-href=/analytics_ang/
